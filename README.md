# tonykim

A Python project with LangChain integration for building AI-powered applications.

## Installation

This project uses LangChain for building applications with Large Language Models (LLMs).

### Prerequisites

- Python 3.7 or higher
- pip (Python package installer)

### Setup

1. Clone this repository:
```bash
git clone https://github.com/kimsoa/tonykim.git
cd tonykim
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

### Verify Installation

Run the test script to verify LangChain is properly installed:

```bash
python3 test_langchain.py
```

## Usage

The project includes:

- `requirements.txt` - Python dependencies including LangChain
- `test_langchain.py` - Installation verification and basic usage examples

### Getting Started with LangChain

LangChain is now installed and ready to use. Here are some key components you can work with:

- **Prompt Templates**: Create reusable prompt structures
- **Chains**: Connect multiple components together
- **Agents**: Build autonomous AI agents
- **Memory**: Add conversation memory to your applications
- **Document Loaders**: Process various document types

For more information, visit the [LangChain Documentation](https://python.langchain.com/).
