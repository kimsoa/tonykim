# tonykim

## LangChain Training Notebook

This repository contains a comprehensive LangChain training notebook that covers the fundamentals of building applications with language models.

### 🚀 Quick Start

1. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Set up Environment Variables** (Optional for basic examples)
   Create a `.env` file in the root directory:
   ```
   OPENAI_API_KEY=your_openai_api_key_here
   ```

3. **Open the Notebook**
   ```bash
   jupyter notebook langchain_training.ipynb
   ```
   Or use Jupyter Lab:
   ```bash
   jupyter lab langchain_training.ipynb
   ```

### 📚 What You'll Learn

- **Basic LLM Usage**: How to work with language models in LangChain
- **Prompt Templates**: Creating reusable and dynamic prompts
- **Chains**: Combining multiple components for complex workflows
- **Memory**: Adding conversation history and context
- **Agents**: Building AI agents that can use tools
- **Document Processing**: Loading and processing various document types

### 📋 Prerequisites

- Python 3.8 or higher
- Basic knowledge of Python programming
- (Optional) OpenAI API key for running LLM examples

### 🔧 Troubleshooting

If you encounter issues:
1. Make sure you have Python 3.8+ installed
2. Try upgrading pip: `pip install --upgrade pip`
3. Install dependencies in a virtual environment:
   ```bash
   python -m venv langchain_env
   source langchain_env/bin/activate  # On Windows: langchain_env\Scripts\activate
   pip install -r requirements.txt
   ```
